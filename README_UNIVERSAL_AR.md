# برنامج المدونة — نسخة موحدة للكمبيوتر وAndroid وiPhone

هذه النسخة مصممة لتعمل من **رابط HTTPS واحد** على الكمبيوتر والهاتف، ولا تحتاج إلى شراء دومين.

## أسهل طريقة: Render

Render يمنحك عنوانًا مجانيًا من نوع:

`https://اسم-الخدمة.onrender.com`

ولا تحتاج إلى شراء دومين. كما يوفر HTTPS تلقائيًا لهذا العنوان.

### 1) أنشئ حساب Render

افتح:
https://render.com/

ثم أنشئ حسابًا مجانيًا واربطه بحساب GitHub.

### 2) ارفع مجلد المشروع إلى GitHub

أنشئ مستودعًا جديدًا، ثم ارفع **كل محتويات هذا المجلد** إلى المستودع.

### 3) انشره في Render

من Render:

`New → Web Service`

اختر مستودع GitHub.

الإعدادات:

- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Plan: Free

يمكن أيضًا أن يقرأ Render ملف `render.yaml` الموجود في المشروع.

بعد النشر سيعطيك Render رابطًا مثل:

`https://almodawana-xxxx.onrender.com`

هذا هو **رابط البرنامج**. لا تحتاج إلى شراء دومين.

## 4) إعداد Google OAuth

في Google Cloud استخدم OAuth Client من نوع **Web application**.

في Authorized JavaScript origins أضف رابط Render الحقيقي، مثل:

`https://almodawana-xxxx.onrender.com`

وإذا أردت تشغيل النسخة محليًا على الكمبيوتر أيضًا، يمكنك إضافة:

`http://localhost:8787`

لا تستخدم عنوانًا تخمينيًا؛ استخدم رابط Render الذي أعطاك إياه حسابك.

فعّل في مشروع Google Cloud:

- Gmail API
- Google Drive API

وأضف حساب Google المستخدم إلى Test users إذا كان OAuth consent screen في وضع Testing.

## 5) استخدام البرنامج على الكمبيوتر والهاتف

بعد نشره، استخدم **نفس رابط Render** على كل الأجهزة.

### الكمبيوتر

افتح الرابط في Chrome أو Edge.

### Android

افتح الرابط في Chrome ثم اختر:
`إضافة إلى الشاشة الرئيسية / Install app`

### iPhone

افتح الرابط في Safari ثم:
`Share → Add to Home Screen`

لا تحتاج Node.js أو XAMPP على الهاتف.

## 6) ربط Gmail وGoogle Drive

من داخل البرنامج:

`الإعدادات → Google OAuth Client ID`

ضع نفس Client ID، ثم اضغط:

`حفظ Client ID → ربط Gmail وGoogle Drive`

سجّل الدخول بحساب Google المطلوب ووافق على الصلاحيات.

**مهم:** تسجيل الدخول يتم مرة على كل جهاز عادةً؛ Google تحفظ جلسة التفويض في المتصفح/الجهاز. هذا لا يعني أن كلمة المرور تنتقل بين الأجهزة، ولا ينبغي تخزين كلمة مرور Google داخل التطبيق.

## 7) ما الذي لا تحتاجه؟

- لا تحتاج شراء Domain.
- لا تحتاج XAMPP.
- لا تحتاج تشغيل الكمبيوتر حتى يعمل البرنامج من الهاتف.
- لا تحتاج Node.js على Android أو iPhone.

## ملاحظة عن الخطة المجانية

الخطة المجانية في Render مناسبة للاختبار والاستخدام الشخصي، لكنها قد توقف الخدمة بعد فترة من عدم الاستخدام ثم تعيد تشغيلها عند أول زيارة. لذلك قد تكون أول فتحة بعد الخمول أبطأ قليلًا.

## البيانات المحلية

قاعدة الأسماء في هذا التطبيق محفوظة في متصفح الجهاز. لذلك **الكمبيوتر والهاتف لا يشتركان تلقائيًا في قاعدة الأسماء المحلية**. أما Gmail وGoogle Drive فيرتبطان بحساب Google الذي تسجل الدخول به على كل جهاز.
